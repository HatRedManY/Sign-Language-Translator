Сюда кладутся два файла, полученные скриптами из tools/sentence:

  sent.ptl   — обученная seq2seq-модель (python export_ptl.py)
  vocab.txt  — словарь выходных токенов (python build_pairs.py)

Пока их нет, приложение собирается и работает как обычно,
а кнопка «Собрать предложение» в истории показывает понятное
сообщение вместо падения.

Порядок действий:

1. Соберите данные и обучите модель по README в tools/sentence
   (он же доступен как E:\Programs\prilojuxa\predlojenia).
2. Скопируйте sentence\sent.ptl и sentence\vocab.txt в эту папку.
3. Пересоберите приложение:
   .\gradlew.bat :app:assembleDebug --no-daemon
4. Установите APK и откройте «История» → «Собрать предложение».

Файлы sent.ptl и vocab.txt — сгенерированные артефакты.
Их можно не хранить в git: при необходимости добавьте их
в .gitignore, но тогда после клонирования репозитория модель
нужно скопировать вручную.
